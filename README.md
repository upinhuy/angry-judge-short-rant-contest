Entry for the make.fun bounty **Angry Judge: The Short Rant Contest**
(`u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046`).

One short, funny rant about an everyday annoyance — a printer that prints
a perfect test page and then jams on the one page you actually need.

## How it works

`main.ts` (pure Node standard library, no network) writes the rant to
`/output/entry.txt`. The entry is UTF-8 text of 1 to 400 characters, as the
bounty gate requires.

Run it locally:

```sh
OUTPUT_DIR=/tmp/rant-test node main.ts
cat /tmp/rant-test/entry.txt
```
